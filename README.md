# Cheddar and Feta

![Cheddar and Feta dancing][dance]

Cheddar and Feta is a 2D RPG and corresponding engine built using [SDL3][sdl]
for cross-platform windowing and graphics, and [libdatachannel][datachannel] for
WebRTC connectivity.
